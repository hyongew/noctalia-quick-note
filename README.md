# Simpler Notes Plugin (aka Quick Note)

A simple notes plugin for [Noctalia Shell](https://github.com/noctalia-dev/noctalia-shell).
Inspired by [@fusuyfusuy](https://github.com/fusuyfusuy)'s [Simple Notes](https://noctalia.dev/plugins/simple-notes/), but I wanted something more minimal, like a sticky note.

## Features
- **Quick Notes**: Save a quick memo that can be accessed from your status bar.
- **Persistence**: Notes are automatically saved.

## Installation

1. Clone or download this repository into your Noctalia plugins directory.
2. Restart Noctalia Shell.
3. Enable "Simpler Notes" in the Noctalia settings if not enabled by default.
4. Add the widget to your bar.

## Usage

- **Bar Widget**: Click the note icon to open the panel.
- **Panel**:
    - Start writing!
